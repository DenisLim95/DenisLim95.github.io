BlueDot Technical AI Safety Puzzle

Correct submission to BlueDot's Technical AI Safety Puzzle #1. The challenge involved analyzing a neural network where one of eight binary features was encoded non-linearly. I identified the non-linear feature (country) using linear and MLP probes, discovered it was represented as a convex polytope bounded by ~34 ReLU hyperplanes, and verified convexity through interpolation tests. For the final task, I trained a model encoding the feature as a quarter-arc in a 2D subspace using custom circle and angular spread losses.
